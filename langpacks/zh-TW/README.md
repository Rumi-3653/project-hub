# 繁体中文の任意言語パック

本体は日本語だけで動きます。このフォルダを本体ルートの `langpacks/zh-TW/` に置き、`HUB_LANG=zh-TW` で起動した時だけ使います。別の場所に置く場合は `HUB_LANGPACK_DIR` にこのフォルダの絶対パスを指定します。変更後はHubを起動し直してください。

パックがない時や読み込めない時は日本語で動きます。訳がない文も日本語になります。`pack.json` の `verifiedWith` は最後に検証した本体の版で、版が違っても読み込みを拒否しません。

`ui.json` は画面、`backend.json` は本体の文言、`native.json` はMacアプリの文言です。既存の翻訳を移したもので、新しい翻訳は追加していません。`docs/` の中国語文書は凍結しており、本体の更新ごとに書き換える必要はありません。

通常の開発では `npm --prefix hub test` を使います。パックを更新・利用する時は `npm --prefix hub run test:langpack` を実行します。未翻訳は警告になり、`HUB_I18N_STRICT=1` を付けると失敗になります。翻訳付き自動更新は、この厳格なパック試験も実行します。

中国語見出しの既存の台帳・作業ファイルを読む互換機能は、本体に残しています。ダウンロードや自動インストールの仕組みはありません。
