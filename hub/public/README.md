# 画面の部品

`index.html` は既存の共通・私有部品の後、下記の classic script を順に読み、最後に `app.js` を実行します。遅延読込みや ES module への変更はありません。

| 部品 | 担当 |
| --- | --- |
| app-tree.js | 左の一覧、通知、階層、一覧の描画 |
| app-project.js | プロジェクトの作成・概要、作業行、受取案内 |
| app-freetalk.js | 話題の履歴・整理・作業への昇格 |
| app-work.js | 作業画面、質問、手順、開閉状態 |
| app-composer.js | 会話の入力、添付一覧、担当・モデルの選択 |
| app-messages.js | 本文の整形、リンク、質問への回答欄 |
| app-files.js | ファイル表示、コピー、場所の表示、ファイル添付 |
| app-chat.js | 会話接続、送信、順番待ちの表示・操作 |
| app-terminal.js | 端末の読込み・接続・開始・後片付け |
| app-settings-ai.js | スキル、AI導入、モデル表示、初期担当、アカウント、私有画面の接続 |
| app-settings.js | 設定画面、役割、復旧、利用権、言語、更新等の表示・操作 |
| app-actions.js | 画面の操作の振り分け、本体フォルダの設定 |

各部品には元の関数宣言と、元のコールバックを生成するだけの関数を移しています。共有する `state`・`view`、下書き・要求番号・処理中フラグなどの状態、共通の操作受付、イベント登録とタイマーの設置位置、私有画面の初期化、起動時の通信は `app.js` の元の位置にあります。機能ごとのイベント本体は部品にあり、副作用のない生成関数から元の登録位置で元のコールバックを受け取ります。コールバック内に外側の this・arguments・new.target の参照がないことを照合しています。追加の状態・通信・登録・タイマーは作りません。

これは既存の `hierarchy.js` 等と同じ大域スコープの classic script です。関数は共有状態を使用時に読み、部品読込み時には読みません。従来の関数名・引数・返り値・エラー伝播・関数オブジェクトに保持する値を維持します。先行する既存部品と後続部品の相対順も維持します。`app.js` の宣言位置に残した `@app-function` / `@app-callback` コメントは元の位置を示す目印で、実行処理はありません。

`test/fixtures/app-source.cjs` の `loadApp` は HTML の順で実際の各 script を読みます。既存の部分切出し試験には、現在の部品の関数本文を元の位置へ展開する `readApp` を使います。期待値や動作の確認項目は変えません。
