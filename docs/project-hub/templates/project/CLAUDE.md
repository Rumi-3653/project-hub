# CLAUDE.md
あなたは Claude Code。役割と作業IDは起動時に伝えられる。

## 始める時（毎回）
1. .ai/rules.md を読む
2. .ai/tasks/<作業ID>.md の最新の再開要約・手順・成果を読む（PROJECT.md と古い全文は必要な所だけ）
3. 自分の役割・作業IDの作業だけする。分けたい時は人に提案する

## 区切りごと・終わる時
- .ai/tasks/<作業ID>.md を更新（変更ファイル・確認結果・残り。state・question・workdir は Hub が管理）
- 「## 手順」の済みを [x]（無ければ3〜5個書く）
- 自分の変更は自分でテストする

## 権限
許可済み作業内の通常操作は再確認不要。削除はゴミ箱へ。大きな変更前に Git に保存。
Hub が用意したコピー内だけで作業。本体反映・push・公開・本番適用は対象・変更・検証を示し人へ最終確認。
料金がかかる操作はしない。

## モデルと長い会話
rules.md の「役割」と「圧縮」に従う。
